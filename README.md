# Amedeo NCC — نسخة Vue (محدّثة)

## تشغيل محلي
```bash
npm install
npm run dev
```
هيفتح على http://localhost:5173

## نشر (build)
```bash
npm run build
```
هيطلعلك مجلد `dist/` جاهز للرفع على Vercel/Netlify.

## اللي اتحدّث في النسخة دي (مقارنة بأول نسخة Vue اللي بعتهالك)
كل التعديلات اللي حصلت على ملف الـ HTML من وقت أول نسخة Vue اتنقلت هنا:

- **9 وجهات كاملة في قسم الرحلات** (روما، بيزا، فينيسيا، كومو، فلورنسا، مدن إيطالية تانية بصورة متغيّرة، باريس، سويسرا، اختار وجهتك) — بدل الـ4 اللي كانوا في نسخة الـ HTML الناقصة
- **زرار على كل كارت** (عربية أو رحلة) بيودّي على فورم الحجز ويملاه تلقائيًا
- **بانر الكوكيز + نافذة سياسة الخصوصية (GDPR)** كاملة
- **SEO كامل** في `index.html`: meta description, Open Graph, Twitter Card, schema.org LocalBusiness (JSON-LD)
- **فوتر بثلاث أعمدة** (تنقل / قانوني / تواصل)
- **قسم التقييمات اتشال بالكامل** — كانت تقييمات شكلها مُختلَق (Maria L., Ahmed K., Giuseppe R.)، وده مخاطرة قانونية لو نُشر. لما يبقى عندك تقييمات حقيقية من عملاء فعليين، ابعتهملي وأرجّعهم
- **زرار الواتساب العائم**: في الركن اليمين السفلي، بـ z-index عالي جدًا (9999) عشان يفضل ظاهر فوق أي حاجة تانية (زي بانر الكوكيز)، ومعاه دعم RTL (بينتقل لليسار تلقائيًا في اللغة العربية)
- شريط "المطار" (departure board) بيترجم صح مع تبديل اللغة

## ملاحظة تقنية عن Vue
النسخة دي مبنية بـ Vue 3 Composition API (`<script setup>`)، فمشكلة الـ "TDZ" (Cannot access 'dict' before initialization) اللي حصلت في نسخة الـ HTML الخام مش ممكن تحصل هنا أصلاً — لأن كل حاجة بتتقرأ من الـ `dict` (زي شريط المطار) موجودة جوه `computed()`، يعني بتتقيّم بس وقت العرض مش فورًا وقت تحميل السكريبت.
